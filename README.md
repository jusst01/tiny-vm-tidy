The machine is a single `while (exit === null)` loop inside one `run` function, with all state in locals: an `Int32Array(256)` data stack and `sp` counter, `Int32Array(256)` memory, a plain array of return addresses, and the input Buffer with a cursor. Dispatch is one if/else-if chain ordered by opcode, and the arithmetic range funnels into a shared block whose inner switch pops two values and selects the operation. Traps never unwind the call stack — each assigns its code to `exit` like `HALT` and `EXIT`, so the loop condition ends the run. Per-opcode pop/push tables drive the underflow and overflow checks, and output chunks are joined with `Buffer.concat` after the loop while a byte counter enforces the 65,536-byte cap before each append.
